# Finding real data (dev stack)

Run SQL with `just db sql [--slot N | --db NAME] "<sql>"` (or `-f file.sql`): the slot's database, Unicode-safe,
`|`-separated with a header, read-only as `ashyq_ro` (emails, bios, IPs, secrets, answers, messages, posts, feedback text,
override notes, AI memory/analyses/drafts, uploaded file names and names on certificates are not readable: select named columns, find people by `username`); `--rw` runs as the owner for writes and email lookups. Sign in as anyone
with `just login-as <username|email> [slot]`; screenshot pages with
`just shoot`. Real data: a slot on a local restored copy (`just stack up 1 --db <name>`, RUNBOOK 5.3); change its rows
freely, never production's.

Every table, column, key and foreign key with the table's purpose: `docs/agents/SCHEMA.md` (generated by
`just schema-docs`; search it before guessing a column). Tables sit in schemas by area (`core`, `learning`, `ai`,
`analytics`, `ops`; ARCHITECTURE §8 rule 8) and the database's `search_path` covers them: write `users`, not
`core.users`; in a catalog query filter `relnamespace::regnamespace::text IN ('public', 'core', 'learning', 'ai',
'analytics', 'ops')`, never `= 'public'`. A database cloned with plain `CREATE DATABASE ... TEMPLATE` lacks the path
(`just db fresh` copies it; else `SELECT ensure_app_search_path()` as the owner).

## Ready queries

A user's id and roles:

```sql
select u.id, u.username, string_agg(r.slug, ',') from users u left join user_roles ur on ur.user_id = u.id
left join roles r on r.id = ur.role_id where u.username = '<login>'
group by 1, 2
```

Published activities of a type in courses a user is enrolled in (types: dynamic, video, document, quiz, exam,
code_challenge, file_submission):

```sql
select a.course_id, a.id, a.name from activities a join enrolments t on t.course_id = a.course_id
join users u on u.id = t.user_id where u.username = '<login>'
and a.kind = 'code_challenge' and a.published limit 5
```

Activities with learner work, most first (good review data):

```sql
select s.assessment_id, a.activity_id, count(*) from submissions s join assessments a on a.id = s.assessment_id
group by 1, 2 order by 3 desc limit 5
```

Courses a teacher can edit:

```sql
select c.id, c.name from courses c join course_staff cs on cs.course_id = c.id
join users u on u.id = cs.user_id where u.username = '<login>' and c.archived_at is null
```

Make a file task reviewable (published, with instructions and a deadline in 3 days; `just db sql --rw`):

```sql
update activities set published = true where id = '<activity>';
update assessments set status = 'published', published_at = now(), due_at = now() + interval '3 days'
  where activity_id = '<activity>';
update file_submissions set instructions = 'Ответьте на вопросы.', max_files = 2 where activity_id = '<activity>';
```

Before deploying points as the record (`20261116075663`, REWRITE 5.8 item 10), on the release before it: handed-in
attempts (previews left out) whose percentage the conversion changes and whose `passed` flips each way. Counts only,
read-only; the migration prints the same counts (NOTICE). The maximum is the one the migration takes: the version's
points, else (a hand-in before versions) the items its breakdown graded at their points now, else the items now, else 100.

```sql
with s as (
  select s.id, s.final_score, s.auto_score, a.passing_score,
         coalesce(v.max_points,
                  nullif((select round(sum(coalesce(case when i.id is not null then greatest(i.max_score, 0) end,
                                                    case when jsonb_typeof(b->'max_score') = 'number'
                                                         then (b->>'max_score')::numeric end, 0)), 2)
                            from jsonb_array_elements(case when jsonb_typeof(g.breakdown->'items') = 'array'
                                                           then g.breakdown->'items' else '[]'::jsonb end) b
                            left join assessment_items i on i.assessment_id = s.assessment_id
                                                        and i.id::text = b->>'item_id'), 0),
                  nullif((select round(sum(greatest(i.max_score, 0)), 2) from assessment_items i
                           where i.assessment_id = s.assessment_id), 0),
                  100) as m
  from submissions s
  join assessments a on a.id = s.assessment_id
  left join assessment_versions v on v.id = s.assessment_version_id
  cross join lateral (select submission_breakdown(s.id, s.auto_breakdown) as breakdown) g
  where s.status <> 'draft' and not s.preview
), d as (
  select *,
         case when m > 0 then round(round(final_score * m / 100, 2) * 100 / m, 2) else final_score * 0 end as final_after,
         case when m > 0 then round(round(auto_score * m / 100, 2) * 100 / m, 2) else auto_score * 0 end as auto_after
  from s
)
select count(*) as attempts,
       count(*) filter (where final_after is distinct from final_score) as percent_changes,
       count(*) filter (where auto_after is distinct from auto_score) as auto_percent_changes,
       count(*) filter (where final_score < passing_score and final_after >= passing_score) as passed_to_true,
       count(*) filter (where final_score >= passing_score and final_after < passing_score) as passed_to_false,
       max(abs(final_after - final_score)) as largest_shift
from d
```

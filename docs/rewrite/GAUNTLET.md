## v1→v2 client drift map (pass 1 survey, 2026-09-10)

The P9 frontend adaptation is incomplete: `apps/web` still calls legacy v1 URL
shapes in many services. Generated by diffing every `apiJson`/`apiResult`/`apiFetch`
literal in `apps/web/src` against `apps/server/openapi.v2.json` (168 routes).
**Candidate mappings — each builder must confirm the target against
`openapi.v2.json` (request DTO, params, response shape) before editing.**
Cursor pagination (`{items, next_cursor}`) replaces `page/limit` + `x-total-count`
everywhere; call sites that read `x-total-count` need rework, not a URL swap.

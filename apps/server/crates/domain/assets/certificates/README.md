# Certificate artwork

`reference.jpg` is the bilingual Toraighyrov University / Ashyq Bilim example supplied by the project owner.
The PDF renderer embeds it unchanged, covers the sample fields, and prints the learner, course, lecturer,
issue date, verification number and optional training dates/hours with embedded Noto Sans fonts.
Previews and issued downloads share this renderer. Blank training details are omitted.

# markdown

Операции:

Один рендер markdown для контента (описания курсов, условия задач и вопросов, отзывы, объявления) и для
ответов AI, и markdown-редактор на ядре Tiptap 3.31 (@tiptap/markdown: markdown на входе и на выходе).
Публичный API (`index.ts`): ленивые `MarkdownView`, `MarkdownEditor`; `sanitize`, `safeUrl`, `safeImageUrl`,
`hasRawHtml`, `markdownPlainText`, `markdownSummary`; `loadHighlighter` (shiki для блоков кода редактора) и
`proseCss` (типографика контента).

## Поведение

- B-MD-01 Рендер: GFM (таблицы, списки задач, зачёркивание), формулы `$...$` и `$$...$$` через KaTeX (грузится,
  только если в тексте есть `$`), блоки кода с подсветкой shiki и подписью языка. Широкая таблица
  прокручивается внутри себя.
- B-MD-02 Ссылки только http(s), mailto, относительные и якоря; остальные без адреса. Внешние открываются в новой
  вкладке с `noopener noreferrer`, внутренние - в приложении.
- B-MD-03 Изображения только из хранилища платформы (`/content/...`); чужие показываются подписью
  «Изображение: alt».
- B-MD-04 Сырой HTML в markdown никогда не исполняется (показывается текстом).
- B-MD-05 `sanitize()` (DOMPurify) - единственный путь HTML-строки в DOM: убирает script, обработчики, style;
  без DOM (SSR) возвращает пустую строку.
- B-MD-06 Простой текст и сводка: разметка снимается, экранированная пунктуация остаётся буквальной (UX-030),
  сводка режется по слову с «…».
- B-MD-07 Markdown-редактор: на входе и выходе markdown; после правки и сохранения рендер даёт то же дерево
  (G-14: все 1051 текста прода проходят без потерь), включая формулы, таблицы и код.
- B-MD-08 Блок кода копирует код кнопкой; подпись кнопки меняется на «Код скопирован».
- B-MD-09 Ответ AI, приходящий потоком, - вежливая live-область (`live`).

## Изменено

- Режимы рендера старого веба (prompt, taskDescription, codeProblem...) сведены к одному виду: размер текста
  задаёт место, где рендер стоит.
- Изображения больше не скрываются флагом `allowImages`: показываются только из хранилища платформы.
- Копирование кода без тоста (тост только после мутации, DESIGN 8).

## Не переносится

- Якорные ссылки у заголовков рендера (были только в описании курса): вернутся с оглавлением курса.
- Пресеты редактора (наборы кнопок по месту), режим исходника, валидация длины и предупреждения о незакрытых
  `$`/```: правила поля задаёт форма-потребитель по схеме контракта.
- Мигающий курсор потока AI: появится с AI-срезом, если нужен (live-область уже есть).
- Списки задач в редакторе: рендер их показывает; в данных прода их нет.

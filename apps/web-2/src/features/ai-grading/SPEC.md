# ai-grading

Операции: gradingSettings, setGradingSettings, gradingMetrics, indexStatus, reindexCourse, gradingConsistency, activityGradeDrafts

AI-предпроверка на уровне курса и активности (docs/AI-FIRST.md 4.4-4.5, 5): вкладка рабочего места курса «ИИ-проверка»
(`/teach/courses/$courseId/ai-grading`) и страница согласованности активности
(`/teach/courses/$courseId/activities/$activityId/consistency`, не вкладка: на неё ведёт очередь работ). Черновики в
очереди и в проверке работы - срез `grading` (B-GRD-40..45). Каталог - `ai_grading`.

## Поведение

- B-AIG-01 Переключатель «Черновики ИИ сразу после сдачи» (`gradingSettings` / `setGradingSettings`) с пояснением, что
  оценку ставит преподаватель; после - сообщение «включены» / «выключены»; отказ (ИИ выключен на платформе, курс в
  архиве) - текст под переключателем.
- B-AIG-02 Период метрик ссылками «7 / 30 / 90 дн.» в URL (`?days=`; 30 - по умолчанию, без параметра); уходит на сервер
  (`days`), неизвестное значение - период по умолчанию.
- B-AIG-03 Итоги за период (`gradingMetrics`): медианное время до отзыва и строка «было N ч · быстрее / медленнее / без
  изменений» к прошлому такому же периоду (меньше - лучше; без одного из чисел строки нет); доля черновиков, принятых
  без правок, среди решённых (как есть, с правкой, отклонено) и эти числа; расхождение ИИ и преподавателя (п. п.);
  сэкономлено часов; черновиков всего, ждут решения, не удалось. Часы и пункты - до десятых; нет числа - прочерк.
- B-AIG-04 «Активности с черновиками» за период: название, черновиков, ждут решения, применены и «К работам» - очередь
  работ активности. Пусто - одна фраза: подготовить черновики можно в очереди.
- B-AIG-05 Карточка «Индекс материалов курса» (`indexStatus`): источники, фрагменты с эмбеддингами из всех, источники с
  ошибкой, последняя индексация (или «Ещё не было»), модель; «Переиндексировать» (`reindexCourse`) показывает ответ
  сервера (обнулённый индекс, его пересоберёт ежеминутный проход) и сообщает «Переиндексация запущена».
- B-AIG-06 Согласованность активности (`gradingConsistency`): «Похожие работы с разными оценками» - вопрос, две работы
  (имя ведёт в проверку работы, рядом её процент), сходство и разница в п. п.
- B-AIG-07 «Оценка далеко от черновика»: балл ИИ и итог преподавателя, разница со знаком (выше ИИ - плюс), «Открыть
  работу».
- B-AIG-08 «Смещение ИИ по критериям»: критерий, вопрос, «ИИ выше / ниже на N п. п.» (или «Без смещения»), число
  исправлений. У каждой из трёх таблиц пустое состояние - одна фраза.
- B-AIG-09 Вопросы и критерии в отчёте названы словами из черновиков активности (`activityGradeDrafts`): заголовок
  вопроса, название критерия; часть работы с файлом и неизвестный вопрос - «Вся работа», неизвестный критерий - его ключ.

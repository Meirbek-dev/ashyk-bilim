# code-arena

Операции: getActivityAssessment, attemptState, mySubmissions, startSubmission, saveSubmissionDraft, submitSubmission, runItem, getCodeRun, listMyCodeRuns, runner, updateItem, referenceCheckItem

Задача с кодом учащегося `/learn/$courseId/$activityId/code` (фокус-режим, вход из карточки плеера) и редактор
вопроса с кодом в студии активности `/teach/courses/$courseId/activities/$activityId/edit` (5.3, 5.4). Редактор кода -
CodeMirror 6 за ленивой границей, режимы только языков платформы (`/code/runner`). Задача с кодом - отдельное
оценивание вида `code_challenge` с одним вопросом `code`: попытка (черновик, сдача) живёт здесь, а не в `/attempt`.
Каталог сообщений - `code`.

## Поведение

- B-COD-01 Страницу задачи открывает только записанный на курс: остальные видят «Нет доступа» на том же адресе (как
  плеер), гость попадает на вход; активность не из курса или другого типа - «Активность не найдена».
- B-COD-02 Задача без вопроса с кодом, без языков или неопубликованная (сервер отвечает учащемуся 404) - «Задача ещё
  не настроена» одной фразой, без редактора и без ошибки.
- B-COD-03 Условие: название, сложность (если задана), лимиты времени и памяти, текст в markdown, форматы ввода и
  вывода, ограничения списком, примеры - видимые тесты (ввод и ожидаемый вывод).
- B-COD-04 Без открытой попытки: использовано попыток и предел (или «без ограничений»), срок; «Начать» по
  `can_start` сервера; иначе причины (`disabled_reasons`) текстом. «Начать» открывает попытку и показывает редактор.
- B-COD-05 Выбор языка - только языки задачи с именами платформы. В редакторе код черновика, иначе стартовый код
  языка. Смена языка заменяет нетронутый код (стартовый или пустой) стартовым кодом нового языка, свой код остаётся.
- B-COD-06 Код уходит в серверный черновик после паузы ввода (`If-Match: draft_version`, один запрос за раз);
  индикатор «Сохранено» / «Сохраняется» / «Есть несохранённые изменения» / «Не сохранено». Перезагрузка
  возвращает код и язык черновика. Черновик, изменённый в другой вкладке (409), - текст «обновите страницу».
- B-COD-07 «Запустить» проверяет код на видимых тестах с `Idempotency-Key` (тот же при повторе без ответа); итог -
  вердикт из перечисления сервера словами (принято, неверный ответ, ошибка компиляции, ошибка выполнения, превышено
  время, внутренняя ошибка, песочница недоступна) и «Пройдено N из M»; вывод компилятора, если есть.
- B-COD-08 Таблица вердиктов: тест (описание или номер), вердикт теста по коду Judge0, время и память; у видимого
  теста - ввод, ожидаемый и полученный вывод. Запуск в адресе (`?run=`): перезагрузка показывает его снова.
- B-COD-09 Отказ запуска (слишком часто, песочница недоступна, язык не разрешён) - текст на месте; без списка
  языков (песочница не настроена) «Запустить» выключена и сказано почему.
- B-COD-10 «Сдать» спрашивает подтверждение (номер попытки и предел) и сдаёт код и язык одним запросом с
  `Idempotency-Key`; после - сообщение «Решение сдано» и результат попытки: статус, балл и «Пройдено тестов N из M»,
  если оценка видна, иначе «Ждёт проверки» или «Оценка появится после публикации».
- B-COD-11 История - все попытки, новые сначала: номер, статус, дата сдачи или «Черновик», балл, если выпущен;
  «Код» открывает код попытки только для чтения с языком (`?submission=`).
- B-COD-12 На 390 px условие над редактором, редактор во всю ширину, кнопки переносятся, горизонтальной прокрутки
  страницы нет.
- B-COD-13 Студия, `edit` задачи с кодом: редактор вопроса; без `update` в `allowed_actions` оценивания поля только
  читаются и «Сохранить» нет.
- B-COD-14 Условие задачи: текст (markdown-редактор), формат ввода, формат вывода, ограничения (по одному в строке).
- B-COD-15 Языки - флажки из языков платформы; стартовый код и эталонное решение - редакторы кода выбранного языка.
  Без списка языков (песочница не настроена) - текст «Список языков недоступен», выбранные языки сохраняются как были.
- B-COD-16 Конструктор тестов: добавить и убрать тест; описание, ввод, ожидаемый вывод, «Видимый» (иначе скрытый),
  вес - целое больше нуля; над списком число видимых и скрытых.
- B-COD-17 Лимиты: время в секундах и память в МБ, целые от 1; пусто - по умолчанию песочницы; ошибка под полем.
- B-COD-18 «Сохранить» активна только при изменениях (и пока название вопроса не совпадает с названием задачи: его
  требует готовность сервера); после - сообщение «Сохранено»; отказ сервера (задача с попытками, в архиве - 409) -
  текст ошибки, введённое не теряется.
- B-COD-19 «Проверить эталон» сначала сохраняет несохранённое, затем запускает сохранённые эталонные решения на всех
  тестах: по каждому языку вердикт, «Пройдено N из M» и сообщение; языку без решения - «Нет эталонного решения».
- B-COD-20 Страница задачи и редактор вопроса работают на kk и en: тексты из каталога, `<html lang>` верный.
- B-COD-21 «Мои запуски» - свои запуски «Запустить», новые сначала (20 последних, `purpose=visible`): дата, вердикт
  и «Пройдено N из M»; «Результаты» открывает таблицу вердиктов запуска (`?run=`), в том числе без открытой попытки.
  Новый запуск сразу встаёт первым; запуски сдач - в истории у своей попытки (B-COD-22).
- B-COD-22 Сданная попытка в истории (`?submission=`) показывает запуск, по которому выставлена оценка
  (`purpose=final`), с таблицей вердиктов по тестам; без такого запуска (ещё не оценена) - только итог попытки.
- B-COD-23 Песочница настроена, но не отвечает (`/code/runner` 503 или отказ запуска, сдачи, проверки эталона с
  `code-runner-degraded` или 5xx): условие, редактор с черновиком (он сохраняется) и история на месте; «Запустить» и
  «Сдать» выключены, текст «Среда выполнения кода временно недоступна» и «Повторить» (читает состояние песочницы
  снова). В студии поля редактируются и «Сохранить» работает, «Проверить эталон» выключена с тем же текстом.

## Изменено

- Monaco заменён CodeMirror 6: подсветка и отступы без IntelliSense, без настроек шрифта, темы и миникарты.
- Задача - свой адрес `/learn/$courseId/$activityId/code`, а не содержимое страницы оценивания.
- Конструктор - вкладка `edit` студии с одной кнопкой «Сохранить»; публикация - переключатель шапки студии (срез
  5.1), готовность - его вкладка `settings`.
- Название вопроса с кодом не редактируется: «Сохранить» пишет в него название задачи (UX-283).
- Опроса запуска нет: `POST .../runs` отвечает готовым запуском, он кладётся в кэш `GET /code-runs/{id}`.

## Не переносится

- Запуск на своём вводе (`custom_input`), сочетания клавиш редактора, сравнение кода двух попыток.
- Правка режима сравнения вывода (`match_mode`) и стратегии оценки (`scoring_strategy`): сохраняются как были.
- Таймер попытки с лимитом времени: срок и лимит видны до начала, сдачу по времени делает сервер.

## Ждёт сервера

- Подсказок в `CodeBody` нет: учащийся их не видит, автор не задаёт (сервер не добавил: в данных их нет, L-6).
- Диапазоны лимитов (`time_limit_seconds`, `memory_limit_mb`) не объявлены и не проверяются сервером.
- `LanguageInfo.monaco_language` назван по Monaco: используется как id режима редактора.
- Нет `allowed_actions` у попытки и запуска: «Запустить» и «Сдать» выводятся из открытого черновика.

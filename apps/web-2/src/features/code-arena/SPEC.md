# code-arena

Операции: getActivityAssessment, attemptState, mySubmissions, startSubmission, saveSubmissionDraft, submitSubmission, runItem, getCodeRun, listMyCodeRuns, runner, updateItem, referenceCheckItem

Задача с кодом учащегося `/learn/$courseId/$activityId/code` (фокус-режим, вход из карточки плеера) и редактор
вопроса с кодом в студии активности `/teach/courses/$courseId/activities/$activityId/edit`. Редактор кода -
CodeMirror 6 за ленивой границей, режимы только языков платформы (`/code/runner`). Задача с кодом - отдельное
оценивание вида `code_challenge` с одним вопросом `code`: попытка (черновик, сдача) живёт здесь, а не в `/attempt`.
Каталог сообщений - `code`.

## Поведение

- B-COD-01 Страницу задачи открывает только записанный на курс: остальные видят «Нет доступа» на том же адресе (как
  плеер), гость попадает на вход; активность не из курса или другого типа - «Активность не найдена».
- B-COD-02 Задача без вопроса с кодом, без языков или неопубликованная (сервер отвечает учащемуся 404) - «Задача ещё
  не настроена» одной фразой, без редактора и без ошибки.
- B-COD-03 Условие: название, сложность (если задана), лимиты времени и памяти, текст в markdown, форматы ввода и
  вывода, ограничения списком, примеры - видимые тесты (ввод и ожидаемый вывод).
- B-COD-04 Без открытой попытки: использовано попыток и предел (или «без ограничений»), срок и что он значит для
  опоздания (как у теста, B-ATT-02); «Начать» по `can_start` сервера; иначе причины (`disabled_reasons`) текстом.
  «Начать» открывает попытку и показывает редактор.
- B-COD-05 Выбор языка - только языки задачи с именами платформы. В редакторе код черновика, иначе стартовый код
  языка. Смена языка заменяет нетронутый код (стартовый или пустой) стартовым кодом нового языка, свой код остаётся.
  Над редактором - часы попытки от `time_remaining_seconds` сервера (лимит времени или строгий срок сдачи, что
  раньше); на нуле код сдаётся сам.
- B-COD-06 Код уходит в серверный черновик после паузы ввода (`If-Match: draft_version`, один запрос за раз);
  индикатор «Сохранено» / «Сохраняется…» / «Есть несохранённые изменения» / «Не сохранено». Перезагрузка
  возвращает код и язык черновика. Черновик, изменённый в другой вкладке (409), - «Черновик изменён в другой вкладке. Обновите страницу.»; курс
  в архиве (409 `course-archived`) - «Курс в архиве: код больше не сохраняется»; задача, снятая с публикации или
  перенесённая в архив под учащимся (404), - «Задача больше недоступна...».
- B-COD-07 «Запустить» проверяет код на видимых тестах с `Idempotency-Key` (тот же при повторе без ответа); итог -
  вердикт из перечисления сервера словами (принято, неверный ответ, ошибка компиляции, ошибка выполнения, превышено
  время, внутренняя ошибка, песочница недоступна) и «Пройдено N из M»; вывод компилятора, если есть.
- B-COD-08 Таблица вердиктов: тест (описание или номер), вердикт теста по его коду (id статусов Judge0, их сохраняет go-judge), время и память; у видимого
  теста - ввод, ожидаемый и полученный вывод. Запуск в адресе (`?run=`): перезагрузка показывает его снова.
- B-COD-09 Отказ запуска (слишком часто, песочница недоступна, язык не разрешён) - текст на месте; без списка
  языков (песочница не настроена) «Запустить» выключена и сказано почему.
- B-COD-10 Без кода «Запустить» и «Сдать» выключены. «Сдать» спрашивает подтверждение (номер попытки и предел) и сдаёт код и язык одним запросом с
  `Idempotency-Key`; после - сообщение «Решение сдано» и результат попытки: статус, балл и «Пройдено примеров: N из M»,
  если оценка видна, иначе «Ждёт проверки» или «Оценка появится после публикации».
- B-COD-11 История - все попытки, новые сначала: номер, статус, дата сдачи или «Черновик», балл, если выпущен;
  «Код» открывает код попытки только для чтения с языком (`?submission=`).
- B-COD-12 Широкий экран: слева условие, «Мои запуски» и «Попытки», справа рабочее место высотой в окно, оно остаётся
  на виду, пока левая колонка прокручивается. На 390 px всё в одну колонку (условие, затем рабочее место во всю
  ширину), панели переносятся, горизонтальной прокрутки страницы нет.
- B-COD-13 Студия, `edit` задачи с кодом: редактор вопроса; без `update` в `allowed_actions` оценивания поля только
  читаются и «Сохранить» нет.
- B-COD-14 Условие задачи: текст (markdown-редактор), формат ввода, формат вывода, ограничения (по одному в строке).
- B-COD-15 Языки - флажки из языков платформы; стартовый код и эталонное решение - редакторы кода выбранного языка.
  Без списка языков (песочница не настроена) - текст «Список языков недоступен», выбранные языки сохраняются как были.
- B-COD-16 Конструктор тестов: добавить и убрать тест; описание, ввод, ожидаемый вывод, «Открытый: виден учащемуся как
  пример» (иначе скрытый), вес - целое больше нуля; над списком «Открытых: N, скрытых: M».
- B-COD-17 Лимиты: время в секундах (1-15) и память в МБ (1-2048), целые; пусто - по умолчанию песочницы; ошибка под полем
  называет предел.
- B-COD-18 «Сохранить» активна только при изменениях (и пока название вопроса не совпадает с названием задачи: его
  требует готовность сервера); после - сообщение «Сохранено»; отказ сервера (задача с попытками, в архиве - 409) -
  текст ошибки, введённое не теряется.
- B-COD-19 «Проверить эталон» сначала сохраняет несохранённое, затем запускает сохранённые эталонные решения на всех
  тестах: по каждому языку вердикт, «Пройдено N из M» и сообщение; языку без решения - «Нет эталонного решения».
- B-COD-20 Страница задачи и редактор вопроса работают на kk и en: тексты из каталога, `<html lang>` верный.
- B-COD-21 «Мои запуски» - свои запуски «Запустить», новые сначала (20 последних, `purpose=visible`): дата, вердикт
  и «Пройдено N из M»; «Результаты» открывает таблицу вердиктов запуска (`?run=`), в том числе без открытой попытки.
  Новый запуск сразу встаёт первым; запуски сдач - в истории у своей попытки (B-COD-22).
- B-COD-22 Сданная попытка в истории (`?submission=`) показывает запуск, по которому выставлена оценка
  (`purpose=final`), с таблицей вердиктов по тестам; без такого запуска (ещё не оценена) - только итог попытки.
- B-COD-26 Без открытой попытки вход начинается с последней сданной: номер, «Зачтено» / «Не зачтено» по проходному
  баллу (когда оценка видна), итог (у сданной с опозданием - и штраф за опоздание; у сданной сама - почему: время
  вышло, срок прошёл) и «Результаты и код» (`?submission=`). Дальше: зачтено или новой попытки нет - главное «Далее:
  <активность>» (B-PLY-18), «Новая попытка» рядом; не зачтено - главное «Новая попытка».
- B-COD-23 Песочница настроена, но не отвечает (`/code/runner` 503 или отказ запуска, сдачи, проверки эталона с
  `code-runner-degraded` или 5xx): условие, редактор с черновиком (он сохраняется) и история на месте; «Запустить» и
  «Сдать» выключены, текст «Запуск кода временно недоступен. Ваш код сохраняется.» и «Повторить» (читает состояние песочницы
  снова); язык без списка платформы назван номером («Язык № 71»), а не «Недоступный язык (№ N)» - так названы только
  языки, которых в списке нет. В студии поля редактируются и «Сохранить» работает, «Проверить эталон» выключена с тем
  же текстом.
- B-COD-27 Задача с ответами (`edit_wording`): условие - текст, форматы ввода и вывода, ограничения - правится и
  сохраняется «Сохранить», не снимая задачу с публикации; языки, стартовый код, эталон, тесты и лимиты только
  читаются, «Проверить эталон» нет; причина - над формой.
- B-COD-28 «Мои запуски»: пять последних, остальные - по «Показать ещё»; открытый по `?run=` запуск дальше пятого
  раскрывает весь список.
- B-COD-24 «Вернуть шаблон» (иконка в панели рабочего места, когда у языка есть стартовый код и текст от него
  отличается) - после подтверждения редактор получает шаблон, черновик сохраняется как обычно.
- B-COD-29 Рабочее место открытой попытки: панель (язык, «Вернуть шаблон», часы, состояние сохранения, настройки,
  сочетания клавиш, «Развернуть» на всё окно), редактор, под ним консоль, внизу «Запустить» и «Сдать». Консоль в
  `?console=`: «Примеры» (видимые тесты по одному: ввод и ожидаемый вывод), «Свой ввод» (поле, заполненное вводом
  первого примера) и «Результат» (запуск из `?run=`; без него - подсказка с клавишей). «Запустить» работает на
  примерах или на своём вводе - что выбрано последним, подпись у кнопки говорит, на чём. Запуск на своём вводе не
  оценивается и не попадает в «Мои запуски»: «Вывод программы» - выполнилось ли, время, память, ввод, вывод, ошибки.
  После любого запуска консоль показывает «Результат».
- B-COD-30 Граница редактора и консоли перетаскивается (мышь, палец) и двигается стрелками (ползунок, 30-85% высоты
  у редактора). Настройки редактора: размер текста (мелкий, средний, крупный), отступ 2 или 4 пробела, перенос
  строк; применяются сразу и вместе с границей запоминаются в браузере для всех задач.
- B-COD-31 Неверный ответ на видимом тесте: в «Получено» выделена первая строка, которая расходится с ожидаемым
  выводом (сравнение как у проверки: без начальных и конечных переводов строк), над ней «Отличие в строке N».
- B-COD-32 Клавиши в редакторе: Ctrl/⌘+Enter - «Запустить», Ctrl/⌘+Shift+Enter - вопрос «Сдать», Ctrl/⌘+S -
  сохранить черновик сейчас (без окна сохранения браузера). Список клавиш - в панели («Сочетания клавиш»).
- B-COD-33 Редактор как настольный: номера строк и сворачивание блоков, несколько курсоров (Alt+щелчок, Ctrl/⌘+D),
  автозакрытие скобок и кавычек, подсказки (свои у Python, JavaScript, TypeScript и Go, у остальных - слова файла;
  слово не повторяется), поиск и замена (Ctrl/⌘+F), переход к строке, комментирование (Ctrl/⌘+/), перенос строк
  Alt+↑/↓; слова поиска - на языке страницы. Под редактором - строка и столбец курсора, выделение и отступ.
- B-COD-25 Тесты задачи - в файл JSON или CSV и из файла (формы старого веба: `input`, `expected_output`, `is_visible`, `weight`); импортированные встают в конец списка с новыми id и сохраняются вместе с заданием; файл другой формы - ошибка.

## Изменено

- Monaco заменён CodeMirror 6: подсветка, подсказки, поиск и настройки (B-COD-30, B-COD-33) без IntelliSense, выбора
  темы и миникарты (цвета - токены темы платформы).
- Задача - свой адрес `/learn/$courseId/$activityId/code`, а не содержимое страницы оценивания.
- Конструктор - вкладка `edit` студии с одной кнопкой «Сохранить»; публикация - переключатель шапки студии,
  готовность - вкладка `settings`.
- Название вопроса с кодом не редактируется: «Сохранить» пишет в него название задачи (UX-283).
- Опроса запуска нет: `POST .../runs` отвечает готовым запуском, он кладётся в кэш `GET /code-runs/{id}`.

## Не переносится

- Сравнение кода двух попыток.
- Правка режима сравнения вывода (`match_mode`) и стратегии оценки (`scoring_strategy`): сохраняются как были.

## Ждёт сервера

- Подсказок в `CodeBody` нет: учащийся их не видит, автор не задаёт (сервер не добавил: в данных их нет, L-6).
- Диапазоны лимитов сервер проверяет (1-15 с, 1-2048 МБ: пределы песочницы), но в контракте они не объявлены: форма
  держит те же числа у себя.
- `LanguageInfo.monaco_language` назван по Monaco: используется как id режима редактора.
- Нет `allowed_actions` у попытки и запуска: «Запустить» и «Сдать» выводятся из открытого черновика.

# analytics

Операции: teacherOverview, adminOverview, atRiskLearners, courseList, courseDetail, assessmentList, assessmentDetail, drillThrough, listInterventions, createIntervention, listSavedViews, saveView, deleteView, exportAtRisk, exportCourseProgress, exportAssessmentOutcomes, exportGradingBacklog

## Поведение

- B-ANL-01 `/teach/analytics` - четыре вкладки-маршрута (overview, learners, performance, operations), пустой адрес ведёт на overview; без `analytics.view` - "нет доступа" на том же адресе (матрица ролей).
- B-ANL-02 Общие фильтры (период 7/28/90 дней, сравнение, шаг день/неделя, курс, группа) - одна схема search-параметров на четыре вкладки; неверное значение в URL заменяется значением по умолчанию; каждый запрос несёт `timezone` платформы.
- B-ANL-03 Вкладка сохраняет общие фильтры и сбрасывает страницу, сортировку и drill-down другой вкладки.
- B-ANL-04 Фильтры применяются кнопкой "Применить": URL обновляется, страница сбрасывается на первую, фильтр переживает перезагрузку; на 390 px фильтры - в листе "Фильтры".
- B-ANL-05 Обзор: шесть плиток KPI - значение текстом, изменение к прошлому периоду со знаком и словом "лучше / хуже" (цвет - второй канал).
- B-ANL-06 Обзор: тренды (активные учащиеся, сданные работы, завершения, проверено) - график на каждый ряд с подписью; значения доступны текстом (таблица для чтения с экрана).
- B-ANL-07 Плитки "активные учащиеся", "завершение" и "ждут проверки" открывают drill-through (`?metric=`): таблица строк за плиткой с номерами страниц; "Скрыть" убирает параметр.
- B-ANL-08 Учащиеся: список в зоне риска (бывшая страница at-risk) - уровень и балл риска, прогресс, дни без активности, динамика, число вмешательств; сортировка по риску, прогрессу, активности и имени живёт в URL; номера страниц.
- B-ANL-09 Учащиеся: над списком - число учащихся с высоким и средним риском и сводка вмешательств (всего, открыто, закрыто, вернулись).
- B-ANL-10 Учащийся открывается панелью (`?learnerId=&courseId=`, адрес можно переслать): история его вмешательств по курсу, новые сверху.
- B-ANL-11 "Записать вмешательство" - диалог (тип, статус, заметка); повтор отправки идёт с тем же `Idempotency-Key`; после успеха - сообщение, запись в истории без повторного запроса и обновлённый счётчик в списке.
- B-ANL-12 Успеваемость: таблицы курсов (завершение, активные, риск, здоровье, не проверено) и заданий (сдача, прохождение, медиана, время проверки) с номерами страниц.
- B-ANL-13 Курс открывается drill-down `?courseId=`: сводка курса и отсев по активностям; курс вне доступа - "не найдено" в области.
- B-ANL-14 Задание открывается drill-down `?assessmentType=&assessmentId=`: сводка, распределение баллов (график и текст) и учащиеся с отметкой "сдал / не сдал" (drill-through `pass_rate`); неизвестное задание - "не найдено" в области.
- B-ANL-15 Операции: плитки очереди проверки (ждут, нарушен срок проверки, медиана до отзыва, прогноз на 7 дней), возраст очереди графиком и текстом, таблица очереди по заданиям.
- B-ANL-16 CSV (зона риска, прогресс курсов, итоги заданий, очередь проверки) - обычные ссылки с текущими фильтрами и `timezone`; видны только с `analytics.export`.
- B-ANL-17 Сохранённые представления: "Сохранить представление" - диалог с именем (пустое - ошибка под полем), сохраняет вкладку и фильтры; представления - ссылки, применяющие фильтры через URL; удаление - подтверждение с названием.
- B-ANL-18 Номера страниц ("Страница N из M", назад и вперёд) есть только в таблицах аналитики; за последней страницей "вперёд" нет.
- B-ANL-19 Пустой список - одна фраза; пустой результат при фильтре - "ничего не найдено" и "Сбросить фильтры".
- B-ANL-20 `/admin/analytics`: рейтинг курсов по здоровью, отдача контента, нагрузка преподавателей, удержание групп, программы; без `admin.analytics` - "нет доступа".
- B-ANL-21 Вкладки и страница администратора работают на kk и en: тексты из каталога, `<html lang>` верный; на 390 px нет горизонтальной прокрутки.

## Изменено

- `/dash/analytics/*` стал `/teach/analytics/{overview,learners,performance,operations}`, админская часть - `/admin/analytics`.
- Отдельные страницы курса, задания и at-risk стали drill-down (search-параметры вкладки); список at-risk слит с вкладкой learners (5.6).
- Вмешательство: четыре кнопки-шаблона с черновиком ремедиации заменены одним диалогом (тип, статус, заметка).
- Графики - `@tanstack/charts` за обёртками кита (`shared/ui/charts`), только токены `--chart-1..5`; у каждого числа есть текст.

## Не переносится

- Выбор часового пояса: платформа одна зона (`Asia/Almaty`), он отправляется всегда.
- `teacher_user_id` (смотреть за другого преподавателя) и `bucket_start` (сужение до одного дня кликом по графику): у старого UI не было элементов управления для них.
- Радары, кольца, gauge и прочие повторы одних и тех же чисел.

## Ждёт сервера

- `allowed_actions` у строк зоны риска: право записать вмешательство сейчас равно праву читать курс, кнопка есть у каждой строки списка (`POST /analytics/teacher/interventions`).
- `DrillThroughResponse.items` - `object[]` без схемы (`GET /analytics/teacher/drill-through/{metric}`): поля читаются локальной схемой Valibot, нужен tagged union по `metric`.
- `SavedView.query` и `SaveViewRequest.query` - свободный object, `view_type` - строка: храним объект фильтров и разбираем схемой фильтров (`/analytics/teacher/saved-views`).
- `CreateInterventionRequest.outcome` - строка с перечислением в описании, нужен enum.
- `reason_codes`, `recommended_action`, `why_now`, `outlier_reason_codes` - строки без enum; `params` у алертов, инсайтов, аномалий, прогнозов и проблем качества данных - свободный object: эти блоки обзора не показываются.
- CSV берёт язык только из `Accept-Language`, ссылка не может его задать: нужен query-параметр языка (`GET /analytics/teacher/exports/*.csv`).
- Правка и закрытие вмешательства: операции нет.

# analytics

Операции: teacherOverview, adminOverview, atRiskLearners, courseList, courseDetail, assessmentList, assessmentDetail, drillThrough, listInterventions, createIntervention, updateIntervention, listSavedViews, saveView, deleteView, getGroup, exportAtRisk, exportCourseProgress, exportAssessmentOutcomes, exportGradingBacklog

## Поведение

- B-ANL-01 `/teach/analytics` - четыре вкладки-маршрута (overview, learners, performance, operations), пустой адрес ведёт на overview; без `analytics.view` - "нет доступа" на том же адресе (матрица ролей).
- B-ANL-02 Общие фильтры (период 7/28/90 дней, сравнение, шаг день/неделя, курс, группа) - одна схема search-параметров на четыре вкладки; неверное значение в URL заменяется значением по умолчанию; каждый запрос несёт `timezone` платформы.
- B-ANL-03 Вкладка сохраняет общие фильтры и сбрасывает страницу, сортировку и drill-down другой вкладки.
- B-ANL-04 Фильтры применяются кнопкой "Применить": URL обновляется, страница сбрасывается на первую, фильтр переживает перезагрузку; на 390 px фильтры - в листе "Фильтры".
- B-ANL-05 Обзор: шесть плиток KPI - значение текстом, изменение к прошлому периоду со знаком и словом "лучше / хуже" (цвет - второй канал).
- B-ANL-06 Обзор: тренды (активные учащиеся, сданные работы, завершения, проверено) - график на каждый ряд с подписью; значения доступны текстом (таблица для чтения с экрана).
- B-ANL-07 Плитки "активные учащиеся", "завершение" и "ждут проверки" открывают drill-through (`?metric=`): таблица строк за плиткой с номерами страниц; "Скрыть" убирает параметр. "В зоне риска" и "курсы с падением активности" ведут во вкладки `learners` и `performance` с теми же фильтрами.
- B-ANL-08 Учащиеся: список в зоне риска (бывшая страница at-risk) - уровень и балл риска, прогресс, дни без активности, динамика, число вмешательств; сортировка по риску, прогрессу, активности и имени живёт в URL; номера страниц.
- B-ANL-09 Учащиеся: над списком - число учащихся с высоким и средним риском и сводка вмешательств (всего, открыто, закрыто, вернулись).
- B-ANL-10 Учащийся открывается панелью (`?learnerId=&courseId=`, адрес можно переслать): история его вмешательств по курсу, новые сверху.
- B-ANL-11 "Записать вмешательство" - диалог (тип, статус, заметка); повтор отправки идёт с тем же `Idempotency-Key`; после успеха - сообщение, запись в истории без повторного запроса и обновлённый счётчик в списке.
- B-ANL-12 Успеваемость: таблицы курсов (завершение, активные, риск, здоровье, не проверено) и заданий (сдача, прохождение, медиана, время проверки) с номерами страниц; сортировка по заголовку столбца (курсы: название, активные, завершение, риск, здоровье; задания: название, сдача, прохождение, время проверки) живёт в URL, как в старом вебе.
- B-ANL-13 Курс открывается drill-down `?courseId=`: сводка курса («Данные на <время>» снимка) и отсев по активностям; курс вне доступа - "не найдено" в области.
- B-ANL-27 Под отсевом курса - путь к завершению (записаны, активны за 7 дней, завершили), учащиеся по главам, состояние курса (давность обновления, средний прогресс, очередь проверки - с важностью), узкие места (активность, признак, завершение, уходы) и ссылки на зону риска и задания этого курса (их вкладки с фильтром курса).
- B-ANL-14 Задание открывается drill-down `?assessmentType=&assessmentId=`: сводка («Данные на <время>»), распределение баллов (график и текст) и учащиеся с отметкой "сдал / не сдал" (drill-through `pass_rate`); неизвестное задание - "не найдено" в области.
- B-ANL-28 Задание: распределение по числу попыток, частые ошибки (вопрос и сколько ошиблись), качество вопросов (верно, различение, ошибки сильных, угадали слабые, слабые варианты), таблица по группам и срок проверки (цель, 90-й процентиль, очередь, просрочено - только при ручной проверке); строки «сдал / не сдал» - с последним баллом, числом попыток и датой сдачи. Drill-through очереди - с датой сдачи и меткой нарушенного срока, прогресса - с шагами «N из M».
- B-ANL-15 Операции: плитки очереди проверки (ждут, нарушен срок проверки, медиана до отзыва, прогноз на 7 дней), возраст очереди графиком и текстом, таблица очереди по заданиям; пустая очередь - одна строка вместо них.
- B-ANL-16 CSV (зона риска, прогресс курсов, итоги заданий, очередь проверки) - обычные ссылки с текущими фильтрами, `timezone` и языком интерфейса (`lang`); видны только с `analytics.export`.
- B-ANL-17 Сохранённые представления: "Сохранить представление" - диалог с именем (пустое - ошибка под полем), сохраняет вкладку и фильтры; представления - ссылки, применяющие фильтры через URL; удаление - подтверждение с названием.
- B-ANL-18 Номера страниц ("Страница N из M", назад и вперёд) есть только в таблицах аналитики; за последней страницей "вперёд" нет.
- B-ANL-19 Пустой список - одна фраза; пустой результат при фильтре - "ничего не найдено" и "Сбросить фильтры".
- B-ANL-20 `/admin/analytics`: рейтинг курсов по здоровью, отдача контента, нагрузка преподавателей, удержание групп, программы; без `admin.analytics` - "нет доступа".
- B-ANL-21 Вкладки и страница администратора работают на kk и en: тексты из каталога, `<html lang>` верный; на 390 px нет горизонтальной прокрутки.
- B-ANL-22 Неизвестная группа в адресе (удалена, чужая ссылка) убирается из адреса до запросов: страница
  открывается без фильтра группы, а не ошибкой 422.
- B-ANL-23 Обзор: блоки "Требует внимания" (алерты) и "Наблюдения" (инсайты); успеваемость: "Прогнозы" и "Аномалии" (из ответа обзора). Пункт - важность словом (сведения / внимание / срочно) и фраза по `code` с подставленными `params`: числа, проценты и часы в формате языка, сигнал узкого места - словом; незнакомое значение параметра показывается как пришло. Пустой блок не показывается.
- B-ANL-24 Зона риска: столбец "Почему сейчас" (`why_now`); панель учащегося - курс, почему сейчас, что сделать (`recommended_action`), признаки риска (`reason_codes`), последнее вмешательство (`last_intervention_type`); задания - столбец "Отклонения" (`outlier_reason_codes`). Тексты - исчерпывающие карты по enum.
- B-ANL-29 Балл риска в списке - с изменением (`risk_score_delta`, со знаком); панель учащегося - из чего риск (`risk_components`: неактивность, отставание, несданные, пропущенные, ждут проверки - баллами, по убыванию) и при `open_grading_blocks` > 0 «Проверить работы (N)» во входящие преподавателя с фильтром курса.
- B-ANL-30 Успеваемость под заданиями - узкие места всех курсов фильтра (`content_bottlenecks` обзора: активность, курс, признак, завершение, уходы), как вкладка успеваемости старого веба.
- B-ANL-36 `/admin/analytics`: «программы» сервера - курсы по автору (`courses_by:<имя>`): столбец «Автор» с именем и `@username` под ним (`author_username`: два автора могут быть тёзками), `unassigned_courses` - «Без автора»; здоровье, завершение и удержание - полосой с числом.
- B-ANL-31 `/admin/analytics`: период рейтингов (7, 28, 90 дней, `?window=`, по умолчанию 28) - меню над таблицами, как фильтр периода старой вкладки администратора.
- B-ANL-32 Операции: «Качество данных» - режим (живые / сводка), последний пересчёт, свежесть, достоверность, исключённые пробные попытки и попытки преподавателей, курсы, где учащихся меньше 5, и замечания сервера к данным (как блок старого веба).
- B-ANL-33 На вкладках - числа: «Обзор» - открытые тревоги, «Учащиеся» - учащиеся в зоне риска (из ответа обзора, как в старом вебе); ноль не показывается. Без курсов в области (`course_options` пуст) - ни вкладок, ни фильтров: одна фраза, что здесь появится, и «Перейти к курсам».
- B-ANL-34 `/admin/analytics`: курс и группа (`?course=`, `?cohort=`) сужают рейтинги - группа и «Удержание групп» (только она) и учащихся «Курсов по авторам», выбор - все курсы и группы платформы по названию (`course_options`, `cohort_options`: рейтинги обрезаны до 25); отдельный список «Отдача контента» (`content_roi`).
- B-ANL-38 Панель учащегося ведёт «Открыть в учащихся курса» - вкладка `learners` курса с поиском по имени (почта, прогресс, активность).
- B-ANL-26 Вмешательство в панели учащегося: итог (`outcome_code`) словами; «Изменить вмешательство» (есть в `allowed_actions`:
  `update`) - статус (`resolved` только с `resolve`), итог, заметки; уходит с `If-Match`, 412 - диалог конфликта.
- B-ANL-35 Блок сигналов сгруппирован по важности (срочно, внимание, сведения): важность - один раз, подзаголовком с иконкой и числом, без значка у каждой фразы.
- B-ANL-37 Сигнал о задании или курсе, чья фраза не называет курс (одноимённые тесты разных курсов), - с названием курса после фразы (`course_name` пункта или `course_options` ответа).
- B-ANL-39 Изменение KPI в процентах (`unit` = `%`) без `delta_pct` - в процентных пунктах («+12 п. п. к прошлому периоду»), счётчики - в единицах.
- B-ANL-25 Сигнал (тревога, вывод, прогноз, аномалия) с `href` - ссылка в нужную вкладку с фильтром: `/teach/analytics/...` как есть, пять путей аналитики старого веба (`/dash/analytics/...`, API в режиме двух вебов) переводятся в вкладки этого; без `href` - drill-down задания или курса из `assessment_*` / `course_id` (прогнозы, аномалии), иначе просто текст.
- B-ANL-40 Сигнал со ссылкой - тихая ссылка (подчёркивание при наведении) со стрелкой справа; сигнал без ссылки - обычный текст без стрелки.
- B-ANL-41 `/admin/analytics`: курс в рейтингах - ссылка на его разбор (`performance?courseId=`), преподаватель - на карточку пользователя (`/admin/users?user=`).
- B-ANL-42 Учащийся в зоне риска: под именем `@username` (тёзки), в панели - «Написать на почту» (`mailto:` по `user_email`) рядом с работами на проверку и «Открыть в учащихся курса» (поиск по username).

## Изменено

- `/dash/analytics/*` стал `/teach/analytics/{overview,learners,performance,operations}`, админская часть - `/admin/analytics`.
- Отдельные страницы курса, задания и at-risk стали drill-down (search-параметры вкладки); список at-risk слит с вкладкой learners (5.6).
- Вмешательство: четыре кнопки-шаблона с черновиком ремедиации заменены одним диалогом (тип, статус, заметка).
- Графики - `@tanstack/charts` за обёртками кита (`shared/ui/charts`), только токены `--chart-1..5`; у каждого числа есть текст.

## Не переносится

- Выбор часового пояса: платформа одна зона (`Asia/Almaty`), он отправляется всегда.
- `teacher_user_id` (смотреть за другого преподавателя): у старого UI не было элемента управления. `bucket_start` (сужение
  списков до одного дня кликом по точке графика, было в старом обзоре): графики нового веба не кликабельны, период
  меняется фильтром.
- Радары, кольца, gauge и прочие повторы одних и тех же чисел.

## Ждёт сервера

- `SavedView.query` и `SaveViewRequest.query` - словарь скаляров без схемы фильтров, `view_type` - строка: разбираем схемой фильтров (`/analytics/teacher/saved-views`).
- `params` (`MessageParams`) - словарь `string | number | string[]` без схемы по `code`: имена параметров читаются по описанию `AnalyticsCode`, нужен tagged union. Список `missing_event_sources.sources` поддерживается контрактом.

## Не перенесено (контракт есть)

- Кнопка вмешательства по `AtRiskLearnerRow.allowed_actions` (`record_intervention`): сейчас есть у каждой строки.
- Drill-through: строки читаются локальной схемой, а не сгенерированным `DrillThroughRow`.

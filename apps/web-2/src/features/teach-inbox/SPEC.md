# teach-inbox

Операции: workQueue

## Поведение

- B-INB-01 `/teach` - одна очередь преподавателя (`GET /work?role=teacher`): работы на проверку и оценки, ждущие публикации, по курсам, где вызывающий автор или соавтор; порядок сервера (приоритет, затем время). Учебные задания самого преподавателя здесь не показываются - они на `/home` (U-03).
- B-INB-02 Строка: активность, курс, состояние по `kind` с подписью ("Проверка просрочена", "Ждёт проверки", "Ждёт публикации"; незнакомый `kind` - "Требует внимания"), с какого дня ждёт и срок, если он есть.
- B-INB-03 Действие строки берётся только из `allowed_actions` (`grade` - "Проверить", `review` - "Открыть оценку") и ведёт прямо в проверку работы `/teach/courses/$courseId/activities/$activityId/submissions/$submissionId`; без id работы - в очередь работ активности `.../submissions`; без известного действия ссылки нет.
- B-INB-04 Фильтр по виду живёт в URL (`?kind=sla_breach|needs_grading|awaiting_release`), варианты - ссылки; неизвестное значение - вся очередь. Число в заголовке - `total` сервера (вся очередь), на вариантах фильтра чисел нет.
- B-INB-05 Фильтр по курсу живёт в URL (`?course=`), меню из курсов загруженных строк; оба фильтра сужают загруженные страницы, "Показать ещё" догружает следующие; пустой результат - "ничего не найдено" и "Сбросить фильтры".
- B-INB-06 "Показать ещё" запрашивает следующую страницу по `next_cursor`; без курсора кнопки нет.
- B-INB-07 Пустая очередь - одна фраза "Ничего не ждёт вашей реакции".
- B-INB-08 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-INB-09 Учебная очередь для `/home` (срез 3.1): `learnerWorkOptions()` из `index.ts` - тот же запрос и те же страницы с `role=learner`.

## Изменено

- `/dash` с секциями "учащийся / преподаватель / администратор" и карточками инструментов стал `/teach`: одна очередь преподавателя; переходы к инструментам - навигация пространства.
- Заголовки и описания строк больше не берутся из ответа (сервер пишет их по-английски): подписи по `kind` из каталога.
- Работы одной активности больше не сворачиваются в одну строку "N работ": каждая строка ведёт в свою работу.
- Автообновление каждые 30 с (UX-068) заменено обновлением при возврате на вкладку (Query); живые события - S-06.

## Не переносится

- Учебная часть `/dash` (возвращённые, ждущие оценки, выставленные, просроченные, начатые) - `/home`, срез 3.1.
- Сигналы администратора (бюджет AI, сводка SLA по преподавателям, аудит доступа) - `/admin`; `/work` их не отдаёт.
- Карточки "готовность курсов" и "создайте первый курс" - `/teach/courses`.

## Ждёт сервера

- Числа по видам на вариантах фильтра: у `WorkQueue` есть только общий `total`.
- Фильтры и сортировка на сервере: у `GET /work` нет `kind`, `course_id`, `sort`; фильтр сужает только загруженные страницы (по 100 строк).
- Id работы: у `WorkItem` нет `submission_id`; он читается из `href` (`?submission=`), а сам `href` - старый адрес `/dash/...`.
- Имя учащегося: только внутри английского `description`, отдельного поля нет.
- Студенты в зоне риска и готовность курсов: `/work` не отдаёт таких `kind` (переход в `analytics/learners` с выбранным студентом и во вкладку `publish` курса появится вместе с ними).
- Живое обновление очереди при новой сдаче - S-06.

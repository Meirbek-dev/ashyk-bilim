# collections

Операции: listCollections, search, getCollection, createCollection, updateCollection, deleteCollection

## Поведение

- B-COL-01 Список публичный: гость видит его без входа, первая страница приходит в SSR-документе; гость видит только публичные коллекции, чужая скрытая по ссылке - "Коллекция не найдена". Коллекцию без доступных курсов видит только автор (сервер, UX-127).
- B-COL-02 "Показать ещё" запрашивает следующую страницу по `next_cursor`; когда курсора нет, кнопки нет.
- B-COL-03 Поиск по названию живёт в URL (`?q=`): переживает перезагрузку и "назад"; пустой результат - "ничего не найдено" и "Сбросить фильтры".
- B-COL-04 Кнопка "Новая коллекция" есть только при праве `collection.create` из сессии (гость и студент её не видят).
- B-COL-05 Свои скрытые коллекции помечены "Скрытая" в списке и на странице коллекции.
- B-COL-06 Создание - диалог (название, описание, видимость); пустое название - ошибка под полем; повтор отправки идёт с тем же `Idempotency-Key`; после успеха - сообщение и страница новой коллекции.
- B-COL-07 Страница коллекции: название, описание, число курсов, дата изменения и курсы со ссылками на их страницы; без курсов - "В коллекции пока нет курсов".
- B-COL-08 Действия "Изменить" и "Удалить" видны только если они есть в `allowed_actions` ответа.
- B-COL-09 Правка - страница `/collections/$collectionId/edit` с заполненными полями; сохранение отправляет `If-Match: version`, после успеха - "Сохранено" и страница коллекции с новыми значениями.
- B-COL-10 Сохранение при чужом изменении (412) открывает диалог конфликта и не теряет ввод; "Обновить и повторить" берёт свежую версию и сохраняет введённое.
- B-COL-11 Правка без права `update` - "нет доступа" на том же адресе; гость уходит на вход.
- B-COL-12 Удаление - подтверждение с названием коллекции, фокус на "Отмена"; после удаления - сообщение и список без неё.
- B-COL-13 Длинное название без пробелов переносится; на 390 px нет горизонтальной прокрутки.
- B-COL-14 Страницы списка, коллекции и правки работают на kk и en: тексты из каталога, `<html lang>` верный.

## Изменено

- Создание было страницей `/collections/new`; теперь диалог с минимумом полей.
- Описание при создании необязательно (контракт), выбор курсов при создании убран.
- Правки в старом вебе не было (только API); теперь есть страница правки.
- Удаление было иконкой на карточке списка; теперь - действие страницы коллекции.
- Номера страниц и "первые 20" заменены на "Показать ещё" (5.6); адрес `/collection/$id` стал `/collections/$collectionId`.
- Мозаика из обложек курсов и значок "Владелец" на карточке убраны: карточка - название, описание, число курсов; права - только `allowed_actions` на странице коллекции.

## Не переносится

- Выбор курсов коллекции (поиск, "выбрать все"): нужен кит-компонент выбора нескольких значений; до него состав задаётся через API.

## Ждёт сервера

- Обложка коллекции: в контракте нет ни поля коллекции, ни назначения загрузки (`shared/api/upload.ts` готов).
- Сортировка списка и поиск с keyset-страницами: у `listCollections` нет `sort` и `q`; поиск идёт через `search` (до 50 совпадений, без "показать ещё").
- Живое обновление списка и страницы при чужих изменениях - S-06.

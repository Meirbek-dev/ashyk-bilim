# learning

Операции: listEnrollments, myCertificatesPage

## Поведение

- B-LRN-01 `/learning` - курсы, которые учащийся начал (`GET /enrollments`): название со ссылкой на страницу курса и прогресс из ответа (`progress_pct`, без пересчёта); без курсов - одна фраза и ссылка в каталог (без «0 курсов» у заголовка).
- B-LRN-02 Состояние курса - `Enrollment.learning_status` сервера: от 100 % - "Завершён", есть прогресс или сданная работа (ждёт оценки) - "В процессе", иначе "Не начат"; у состояния есть подпись, не только цвет.
- B-LRN-03 Фильтр по состоянию живёт в URL (`?state=in_progress|not_started|completed`), у каждого варианта число курсов; неизвестное значение - весь список; пустой результат фильтра - "ничего не найдено" и "Сбросить фильтры".
- B-LRN-04 Действие карточки ("Продолжить" / "Начать") ведёт в следующую активность курса (`next_activity_id`), как в старом вебе; у завершённого, архивного курса или без следующей активности ("Открыть курс") - на страницу курса.
- B-LRN-05 Курс без опубликованных активностей показывает "В курсе пока нет опубликованных активностей" вместо "0 %" (UX-232).
- B-LRN-06 Архивные курсы остаются в списке с меткой "В архиве" и стоят после остальных.
- B-LRN-07 "Мои сертификаты" (`GET /me/certificates/page`, "Показать ещё" по `next_cursor`): курс со ссылкой, дата выдачи, преподаватель, код; "Скачать PDF" - обычная ссылка на PDF сервера; "Подлинность" ведёт на `/certificates/$certificateId/verify`; без сертификатов - одна фраза.
- B-LRN-08 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-LRN-09 Порядок карточек: сначала «В процессе», затем «Не начат», затем «Завершён» (внутри группы - порядок сервера),
  архивные - в конце (B-LRN-06). Курс без следующей активности ведёт на страницу курса кнопкой «Открыть курс».
- B-LRN-10 В одну колонку (телефон) курс - строка с миниатюрой обложки слева, в сетке от двух колонок - карточка с обложкой.
- B-LRN-11 Есть сертификаты - в шапке ссылка «Сертификаты: N» (N+ при следующей странице) к списку «Мои сертификаты» под курсами.

## Изменено

- Адрес `/trail` стал `/learning`.
- Лидерборд и лента XP ушли с этой страницы в `/achievements`.
- Строка сертификата под каждым курсом заменена одним списком "Мои сертификаты" (снимает UX-252: у курса без сертификации нет строки "недоступен").
- Счётчик "N / M шагов" убран: прогресс - процент из ответа, состояние - подпись.
- Обложки курса на карточке нет: карточка - название, состояние, прогресс, действие.

## Не переносится

- Выход из курса ("Покинуть курс") - действие страницы курса (срез `course`, операция `leaveCourse`).

## Ждёт сервера

- Живое обновление прогресса после ручной отметки в другой вкладке: в `UserStreamEvent` нет события прогресса (сдачи
  приходят `submission.updated`).

## Не перенесено (контракт есть)

- "Показать ещё" у курсов: `GET /enrollments` принимает `limit` и `cursor`.

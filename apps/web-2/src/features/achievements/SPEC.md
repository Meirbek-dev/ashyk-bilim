# achievements

Операции: dashboard, leaderboard, recordStreak, xpHistory

## Поведение

- B-ACH-01 `/achievements` - только для вошедших: гость уходит на вход и возвращается сюда.
- B-ACH-02 Уровень, всего XP и полоса прогресса до следующего уровня берутся только из полей сервера (`level_progress_percent`, `xp_to_next_level`; UX-064); на последнем уровне вместо остатка - «Максимальный уровень».
- B-ACH-03 Серии входов и учёбы: текущая и лучшая. Серия, последний день которой раньше вчерашнего (сутки UTC, как на сервере), показывается как 0.
- B-ACH-04 Рейтинг: место, имя со ссылкой на публичный профиль, уровень и XP; при равном XP место общее; своя строка отмечена «Вы» по `user_id`, а не по номеру места (UX-172).
- B-ACH-05 Над рейтингом - «Ваше место: N из M», даже если своей строки нет среди загруженных (UX-185); скрытый из рейтинга видит «Вас нет в рейтинге». Рядом - ссылка на `/settings/notifications`, где живёт эта настройка.
- B-ACH-06 «Показать ещё» загружает следующие 20 мест по `next_cursor` (keyset): строки не сдвигаются между страницами; на последней странице кнопки нет.
- B-ACH-07 Лента: последние начисления XP - источник, причина от администратора, дата и сумма; без начислений - «Начислений пока нет».
- B-ACH-08 `StreakBadge` для `/home`: «пилюли» уровня (кольцо прогресса, «Уровень N · X XP») и активной серии учёбы («Серия учёбы: N дней»), обе ведут на `/achievements`; без активной серии - только уровень; с выключенными наградами - ничего.
- B-ACH-11 Строка серии на `/home` скрыта, если в настройках выключено «Показывать XP, уровни и награды»
  (`display.show_gamification`) или «Показывать серию учёбы на главной» (`display.show_streaks`).
- B-ACH-13 С выключенным «Показывать XP, уровни и награды» пункта «Достижения» нет в навигации (боковая и нижняя
  панели, палитра); страница по прямой ссылке открывается.
- B-ACH-12 Лента - вся история XP (`GET /gamification/xp/history`), новые сверху, «Показать ещё» по `next_cursor`;
  `xp.awarded` перечитывает её.
- B-ACH-14 «XP за сегодня» (`daily_xp` дашборда): «N из L XP (дневной лимит)» с полосой, при достижении - «Дневной лимит L XP исчерпан. Новые XP начислятся завтра.», без лимита - «N XP, без дневного лимита» без полосы (сутки UTC, как начисления).
- B-ACH-15 На узкой «Сегодня» (телефон) пилюли в одну строку: «200 XP» у кольца уровня и «3 дня» у огонька; полный текст остаётся именем ссылки.
- B-ACH-09 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-ACH-10 Серию входов двигает только `POST /gamification/streaks/login` (при входе сервер её не трогает): `/home` вызывает его раз в сутки UTC на сессию браузера (`useLoginStreak`, отметка дня в sessionStorage до запроса); ответ (обе серии) кладётся в профиль в кэше, без повторного чтения панели.

## Изменено

- Геймификация ушла с главной и из `/trail`: свой раздел `/achievements`; курсы и сертификаты `/trail` - срез `learning`.
- Названия уровней («Новичок», «Мастер»...) и «следующая веха» убраны: это были таблицы клиента, расходившиеся с сервером (UX-064).
- Рейтинг - полный список с «Показать ещё» вместо «топ-3 + окрестность» и «Показать все / меньше» в прокрутке.
- Аватары с бейджем уровня заменены инициалами.
- Настройки видимости и сообщений об XP не дублируются: ссылка на `/settings/notifications`.

## Не переносится

- «N XP до <имя>» (отставание от следующего места): считалось только по загруженным строкам и называло не того (UX-197).
- Стрелки изменения места: поля нет в контракте, старый веб их не получал.
- Поздравления и эмодзи серий («Вы в огне!»): декоративный текст (DESIGN 11).

## Ждёт сервера

- Серии не пересчитываются при чтении (сервер сбрасывает их только при следующей записи): веб сравнивает дни сам.
- `source_id` начисления - непрозрачная строка без названия курса или активности, ссылки из ленты нет.

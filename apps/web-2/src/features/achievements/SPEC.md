# achievements

Операции: dashboard, leaderboard

## Поведение

- B-ACH-01 `/achievements` - только для вошедших: гость уходит на вход и возвращается сюда.
- B-ACH-02 Уровень, всего XP и полоса прогресса до следующего уровня берутся только из полей сервера (`level_progress_percent`, `xp_to_next_level`; UX-064); на последнем уровне вместо остатка - «Максимальный уровень».
- B-ACH-03 Серии входов и учёбы: текущая и лучшая. Серия, последний день которой раньше вчерашнего (сутки UTC, как на сервере), показывается как 0.
- B-ACH-04 Лидерборд: место, имя со ссылкой на публичный профиль, уровень и XP; при равном XP место общее; своя строка отмечена «Вы» по `user_id`, а не по номеру места (UX-172).
- B-ACH-05 Над лидербордом - «Ваше место #N из M», даже если своей строки нет среди загруженных (UX-185); скрытый из лидерборда видит «Вас нет в лидерборде». Рядом - ссылка на `/settings/notifications`, где живёт эта настройка.
- B-ACH-06 «Показать ещё» загружает следующие 20 мест по `offset`; когда загружены все участники, кнопки нет; строка, сдвинувшаяся между страницами, не повторяется.
- B-ACH-07 Лента: последние начисления XP - источник, причина от администратора, дата и сумма; без начислений - «Пока нет начислений».
- B-ACH-08 `StreakBadge` для `/home`: одна строка «Серия учёбы: N дней» со ссылкой на `/achievements`; без активной серии - ничего.
- B-ACH-09 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.

## Изменено

- Геймификация ушла с главной и из `/trail`: свой раздел `/achievements` (5.4, 5.6); курсы и сертификаты `/trail` - срез `learning`.
- Названия уровней («Новичок», «Мастер»...) и «следующая веха» убраны: это были таблицы клиента, расходившиеся с сервером (UX-064).
- Лидерборд - полный список с «Показать ещё» вместо «топ-3 + окрестность» и «Показать все / меньше» в прокрутке.
- Аватары с бейджем уровня заменены инициалами (5.4: «украшенные аватары» убраны).
- Настройки видимости и сообщений об XP не дублируются: ссылка на `/settings/notifications`.

## Не переносится

- «N XP до <имя>» (отставание от следующего места): считалось только по загруженным строкам и называло не того (UX-197).
- Стрелки изменения места: поля нет в контракте, старый веб их не получал.
- Поздравления и эмодзи серий («Вы в огне!»): декоративный текст (DESIGN 11).
- Вызов `recordStreak`: серию входов сервер пишет при входе, серию учёбы - при завершении активности (старый веб его тоже не вызывал).

## Ждёт сервера

- Тосты начисления XP и повышения уровня - событием потока (S-06, S-13).
- Лидерборд на keyset (S-05): сейчас `limit` / `offset`, строки сдвигаются между страницами; веб убирает повторы.
- XP за сегодня: дневной лимит читается только с `platform:manage` (`GET /gamification/config`), а `daily_xp_earned` не обнуляется до следующего начисления.
- Серии не пересчитываются при чтении (сервер сбрасывает их только при следующей записи): веб сравнивает дни сам.
- История начислений: `GET /gamification` отдаёт только 10 последних, операции со страницами нет; `source_id` - непрозрачная строка без названия курса или активности, ссылки из ленты нет.
- `Profile.preferences` без типа (`{[key]: unknown}`), ключи в camelCase (`showOnLeaderboard`, `xpGain`, `animatedEffects`, `compactMode`; C-11, S-10).
- Отключение геймификации целиком (5.4, строка серии на `/home`): в `PreferencesPatch` нет такого поля.

# certificates

Операции: verifyCertificate, certificatePdf, certificationPreviewPdf

## Поведение

- B-CRT-01 `/certificates/$certificateId/verify` публичная (это адрес с выданного PDF, `$certificateId` - код проверки): гость получает в SSR-документе состояние "Сертификат действителен", владельца, курс со ссылкой, сертификат (название и тип из настроек курса, если заданы), дату выдачи, преподавателя и код; название и тип есть и в «Моих сертификатах» (`/learning`).
- B-CRT-02 Неизвестный код - "Сертификат не найден" (и в заголовке вкладки) с меткой "Недействителен" и проверенным кодом, документ отвечает 404; код без учёта регистра и дефисов (сервер).
- B-CRT-03 `head` страницы: `title`, `description`, `og:title` и `og:description` с владельцем, курсом и датой выдачи - для ссылки в мессенджере.
- B-CRT-04 "Скачать PDF" - ссылка на `GET /certificates/{code}/pdf?lang=<язык интерфейса>` (сервер отдаёт `attachment`), URL строит сгенерированный клиент; тело в JS не читается.
- B-CRT-05 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-CRT-06 Адрес с выданного PDF `/{ru|kz|en}/certificates/$certificateId/verify` показывает ту же страницу проверки на языке сертификата (`kz` - kk) уже в SSR-документе, не трогая язык посетителя (cookie `ab_locale`): переход дальше - на его собственном языке; другой префикс - "Страница не найдена" (и в заголовке вкладки).
- B-CRT-07 Действительный сертификат - на обложке его курса: печать, имя владельца крупно, затем курс, сертификат,
  преподаватель и код; заголовок страницы - название курса, «Скачать PDF» - главное действие.
- B-CRT-08 На «Сертификат не найден» - поле «Проверить другой код» с введённым кодом: «Проверить» открывает проверку
  набранного кода (опечатку исправляют на месте).
- B-CRT-09 Поделиться: на странице проверки и в «Моих сертификатах» - «Скопировать ссылку» (адрес страницы проверки;
  кнопка отвечает «Ссылка скопирована»); в «Моих сертификатах» ещё «Добавить в LinkedIn» - форма LinkedIn с названием
  (своё название сертификата, иначе курса), выдавшим (Ashyq Bilim), месяцем выдачи, кодом и адресом проверки.

## Изменено

- PDF только серверный (BUG-383): браузер его не собирает.
- `/{ru|kz|en}/certificates/$certificateId/verify` - намеренный канонический псевдоним для напечатанных QR-кодов, не редирект: адрес на бумаге не меняется, страница открывается на его языке. Это единственный адрес нового веба с локалью.
- Превью оформленного сертификата на странице проверки убрано: страница отвечает "подлинный ли он и чей", документ - это PDF.

## Не переносится

- Настройка и предпросмотр сертификата курса - студия курса (срез 4.1, `settings`, B-CST-21, B-CST-37); здесь только
  адрес предпросмотра (`certificationPreviewHref`), рядом с адресом PDF.

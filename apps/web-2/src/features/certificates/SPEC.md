# certificates

Операции: verifyCertificate, certificatePdf

## Поведение

- B-CRT-01 `/certificates/$certificateId/verify` публичная (это адрес с выданного PDF, `$certificateId` - код проверки): гость получает в SSR-документе состояние "Сертификат действителен", владельца, курс со ссылкой, дату выдачи, преподавателя и код.
- B-CRT-02 Неизвестный код - "Сертификат не найден" с меткой "Недействителен" и проверенным кодом, документ отвечает 404; код без учёта регистра и дефисов (сервер).
- B-CRT-03 `head` страницы: `title`, `description`, `og:title` и `og:description` с владельцем, курсом и датой выдачи - для ссылки в мессенджере.
- B-CRT-04 "Скачать PDF" - ссылка на `GET /certificates/{code}/pdf` (сервер отдаёт `attachment`), URL строит сгенерированный клиент; тело в JS не читается.
- B-CRT-05 Страница работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-CRT-06 Адрес с выданного PDF `/{ru|kz|en}/certificates/$certificateId/verify` показывает ту же страницу проверки на языке сертификата (`kz` - kk) уже в SSR-документе и сохраняет этот язык в cookie; другой префикс - "Страница не найдена".

## Изменено

- PDF только серверный (BUG-383): браузер его не собирает.
- `/{ru|kz|en}/certificates/$certificateId/verify` - намеренный канонический псевдоним для напечатанных QR-кодов, не редирект: адрес на бумаге не меняется, страница открывается на его языке. Это единственный адрес нового веба с локалью.
- Превью оформленного сертификата на странице проверки убрано: страница отвечает "подлинный ли он и чей", документ - это PDF.

## Не переносится

- Настройка и предпросмотр сертификата курса - студия курса (срез 4.1, `settings`).

## Ждёт сервера

- Ссылка в PDF: сервер печатает `{/ru|/kz|/en}/certificates/{code}/verify` (`Language::web_prefix`, UX-039); веб принимает её псевдонимом (B-CRT-06), менять сервер не обязательно.
- Название и тип сертификата лежат только в непрозрачном `Certification.config` (документ дизайнера); у `VerifiedCertificate` нет поля названия - страница называет курс.
- Язык PDF берётся из `Accept-Language` браузера, а не из выбранного языка интерфейса: у `GET /certificates/{code}/pdf` нет параметра языка.

# discussions

Операции: listDiscussions, listReplies, getDiscussion, createDiscussion, updateDiscussion, deleteDiscussion, toggleLike, toggleDislike

Вкладка `/courses/$courseId/discussions`: посты курса и один уровень ответов. Открытый тред - search-параметр
`?thread=<id>`: пост берётся из загруженных страниц списка, а если его там нет - из `GET /discussions/{id}`;
ответы - из `listReplies`.

## Поведение

- B-DSC-01 Гость видит приглашение войти со ссылкой на вход и `redirect` обратно, а не обсуждения (API читает их
  только вошедшим, UX-109).
- B-DSC-02 Посты новые сверху, по 20; «Показать ещё» по `next_cursor`, без курсора кнопки нет. Нет постов -
  «Обсуждений пока нет».
- B-DSC-03 Новый пост - редактор пресета `discussion`; пост без текста - ошибка под полем, без запроса; отправка с
  `Idempotency-Key`, повтор после сбоя сети - с тем же ключом (BUG-153); после успеха - сообщение, пост первым в
  списке, поле пустое.
- B-DSC-04 «Ответы (N)» открывает тред под постом и пишет `?thread=<id>` в адрес (переживает перезагрузку и
  «назад»); ответы по порядку, «Показать ещё» по курсору; «Скрыть ответы» закрывает тред.
- B-DSC-05 Ответ - только при `reply` в `allowed_actions` поста; после успеха ответ в конце треда.
- B-DSC-06 «Изменить» (при `update`) открывает редактор с текущим текстом; «Сохранить» сохраняет, «Отмена» - без
  изменений. Отметки «изменено» нет.
- B-DSC-07 «Удалить» (при `delete`) - подтверждение; у поста - что ответы удалятся вместе с ним; после - сообщение,
  поста или ответа больше нет.
- B-DSC-08 Модерация (при `moderate`): «Скрыть» и «Вернуть» меняют статус; скрытый пост помечен «Скрыт». Владелец
  без `moderate` статус не меняет (BUG-115).
- B-DSC-09 «Нравится» и «Не нравится» (при `react`) - переключатели; счётчики и нажатость из ответа сервера.
- B-DSC-10 Ответы мутаций кладутся в кэш списка и треда: после создания, правки, удаления и реакции страница не
  перечитывает список; счётчик ответов поста берётся из `parent_replies_count` ответа на создание.
- B-DSC-11 Вкладка работает на kk и en: тексты из каталога, `<html lang>` верный.
- B-DSC-12 Ссылка на тред поста, которого нет на первой странице, показывает этот пост открытым над списком;
  неизвестный, скрытый пост или ответ - только список.
- B-DSC-13 Удаление поста или ответа уходит с `If-Match: version`; 412 - текст в окне подтверждения.

## Изменено

- Обсуждения были блоком внизу страницы курса - теперь вкладка `discussions`.
- Все страницы постов с ответами грузились разом (BUG-352) - теперь «Показать ещё», ответы - по открытию треда.
- Опрос каждые 15 с и перечитывание при фокусе (UX-062) убраны: опросов нет (7.7), живые обновления - S-06.
- Счёт «за минус против» заменён двумя счётчиками.
- Появилась модерация (скрыть и вернуть): статус был в API, кнопки не было.

## Не переносится

- Однострочное приглашение, раскрывающееся в редактор: редактор поста виден сразу.

## Ждёт сервера

- Живые обновления чужих постов: в `UserStreamEvent` нет событий обсуждений.

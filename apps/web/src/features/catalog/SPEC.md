# catalog

Операции: getPlatform, listCourses, search

## Поведение

- B-CAT-01 Лендинг `/` - для гостя, приходит в SSR-документе: название платформы, описание (пустое - общая фраза), «о платформе»; вошедший уходит на `/home` (оболочка).
- B-CAT-02 На лендинге «как начать» (регистрация - главное действие, каталог), до 6 последних публичных курсов со ссылками и «Весь каталог» на `/courses`; без курсов - фраза вместо списка.
- B-CAT-03 Каталог `/courses` публичный, первая страница в SSR-документе; карточка - название (ссылка на `/courses/$courseId`), описание, дата изменения; свой неопубликованный курс помечен «Не опубликован», архивный - «В архиве».
- B-CAT-04 «Показать ещё» запрашивает следующую страницу по `next_cursor`; когда курсора нет, кнопки нет.
- B-CAT-05 Поиск по названию и описанию живёт в URL (`?q=`): переживает перезагрузку и «назад»; пустой результат - «ничего не найдено» и «Сбросить фильтры»; пустой каталог без фильтра - «Курсов пока нет».
- B-CAT-06 Сортировка в URL (`?sort=updated|name|progress`): по умолчанию вошедшему - «Сначала начатые» (progress), гостю - «Сначала новые» (updated); «Сначала начатые» гостю не предлагается; неизвестное значение - как по умолчанию.
- B-CAT-07 Поиск `/search?q=` показывает курсы, коллекции и людей из одного ответа `search`; ссылки-фильтры `?kind=courses|collections|users` с числом найденного; неизвестный `kind` - «Все».
- B-CAT-08 Гость не видит раздела «Люди» (контракт отдаёт его только вошедшим).
- B-CAT-09 Без запроса - приглашение ввести запрос; запрос без совпадений (в том числе из одних знаков препинания) - «ничего не найдено» и «Сбросить фильтры», не ошибка.
- B-CAT-10 Палитра команд открывается `Ctrl/Cmd+K` и кнопкой поиска в верхней панели на любой странице оболочки; `Esc` закрывает.
- B-CAT-11 Переходы палитры - только разделы, которые пользователь может открыть (`shared/auth/access.ts`), сгруппированы по пространствам; у гостя переходов нет.
- B-CAT-12 Ввод в палитре ищет курсы, коллекции и людей (`search`, с задержкой); выбор результата открывает его страницу; «Все результаты» открывает `/search?q=`.
- B-CAT-13 `?` вне полей ввода и пункт палитры «Сочетания клавиш» показывают список сочетаний из одного реестра.
- B-CAT-14 Лендинг, каталог и поиск работают на kk и en: тексты из каталога, `<html lang>` верный.

## Изменено

- Лендинг больше не показывает весь каталог: `/` (что это, как начать, несколько курсов) и `/courses` (каталог) - разные страницы; вошедший на `/` попадает на `/home`.
- Номера страниц каталога (`?page=`) заменены на «Показать ещё» (5.6).
- В каталоге появились поиск и сортировка (контракт `q`, `sort`); старый каталог всегда шёл в порядке «сначала начатые».
- Карточка курса - название, описание, дата и статус; обложка, полоса прогресса, кнопка «Начать / Продолжить», значок «Владелец» и меню правки убраны с карточки: главное действие и правка - на странице курса и в студии.
- Строка поиска в шапке заменена палитрой команд (`Ctrl/Cmd+K`); фильтр поиска `?type=` стал `?kind=`, номера страниц поиска убраны.

## Не переносится

- Действия палитры по правам (создать курс, коллекцию): у создания нет адреса (это диалог на странице списка); палитра ведёт на сам список.

## Не перенесено (контракт есть)

- Авторы на карточке: `CourseListItem.authors`.
- Прогресс вошедшего на карточке: `CourseListItem.progress`.
- «Показать ещё» в поиске: `GET /search` принимает `cursor`, отвечает `next_cursor`.

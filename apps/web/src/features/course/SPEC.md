# course

Операции: getCourse, getCurriculum, learnerCourseState, listContributorsPage, enroll, leaveCourse, applyContributor, removeContributor, listCourseUpdatesPage

Страница курса `/courses/$courseId/{about,updates,discussions}` (5.3, 5.4): шапка `DetailPage` с одним главным
действием, вкладки - дочерние маршруты. Обсуждения - фича `discussions`.

## Поведение

- B-CRS-01 Страница публична: гость получает название, авторов, описание и программу в SSR-документе; неизвестный,
  битый или скрытый от него id - «Курс не найден» (сервер не различает их, UX-078).
- B-CRS-02 Шапка: название, строка «Авторы: ... · Обновлено <дата>» (активные авторы из списка соавторов, создатель
  первым; наблюдатели не показываются - сервер, BUG-146), метка «В архиве» у архивного курса; обложка
  `/content/<thumbnail_key>` вверху вкладки `about`.
- B-CRS-03 Гость: главное действие «Записаться» ведёт на вход с `redirect` обратно на страницу курса (UX-021).
- B-CRS-04 Вошедший без записи и с `permissions.can_enroll`: «Записаться» отправляет запись; после успеха -
  сообщение и главное действие из нового состояния сервера («Начать»), без перезагрузки (UX-119). Кнопки действий
  курса (запись, выход, заявка) доступны после гидрации: нажатие, повторённое React посреди гидрации, меняло шапку.
- B-CRS-05 Записанный: главное действие ведёт в плеер `/learn/$courseId/<next_action.activity_id>`, подпись по
  `next_action.id` («Начать», «Продолжить», «Исправить работу», «Посмотреть отзыв», «Открыть»); без следующей
  активности у пройденного курса - «Итоги курса» (`/learn/$courseId/complete`, UX-053).
- B-CRS-06 Персонал курса (`can_enroll` нет, в `allowed_actions` есть `update`) не записывается: главное действие -
  «Рабочее место курса» (BUG-287).
- B-CRS-07 Выход из курса - только у записанного, через подтверждение с названием курса (фокус на «Отмена»); после
  выхода - сообщение и снова «Записаться» (BUG-074, BUG-077).
- B-CRS-08 Описание: `description` - markdown через общий рендер; пустое - показывается `about`. «Чему вы научитесь»
  - список `learnings` по порядку, без пустого раздела.
- B-CRS-09 Программа: главы и активности по порядку, у активности иконка и подпись типа из `activityTypeMeta`.
  Гостю - опубликованные активности из `getCurriculum`, вошедшему - `outline` состояния учащегося. Курс без
  активностей - «В курсе пока нет активностей» (UX-008).
- B-CRS-10 Прогресс записанного только из ответа сервера: «Пройдено N из M», полоса `progress_pct`, отметка
  «Пройдено» у завершённых активностей; доступные активности - ссылки в плеер. Ничего не считается на клиенте.
- B-CRS-11 Соавторство на курсе с `open_to_contributors`: вошедший без своей строки в списке - «Стать соавтором»;
  со своей заявкой `pending` - «Заявка на рассмотрении» и «Отозвать заявку» (UX-023); ответ 403 или 404 при отзыве
  (заявку уже приняли или отклонили) - сообщение и свежий список (UX-050).
- B-CRS-12 Вкладка `updates`: объявления курса (заголовок, текст markdown, дата), видны и гостю, «Показать ещё» по
  `next_cursor`; пусто - «Объявлений пока нет».
- B-CRS-13 Страницы курса работают на kk и en: тексты из каталога, `<html lang>` верный.

## Изменено

- Объявления были карточкой «Updates» на странице (только для вошедших) - теперь вкладка `updates`, видна всем.
  Создание и удаление объявлений - в рабочем месте курса, не здесь.
- AI-хаб с вкладками в состоянии убран со страницы курса; панель AI придёт срезом 6.3 (у `DetailPage` нет слота).
- Обсуждения были блоком внизу страницы - теперь вкладка `discussions`.
- Выход из курса был только на карточке `/trail` - теперь на странице курса, с подтверждением.
- Адрес `/course/$id` стал `/courses/$courseId/about`; карточка CTA сбоку и модальное окно прогресса сведены к
  одному главному действию в шапке и строке прогресса во вкладке.
- «Продолжить» больше не записывает молча заново: действие берётся из `next_action` сервера.
- Аватары авторов заменены именами в строке шапки; главы не сворачиваются.

## Не переносится

- Видео-обложка (`thumbnail_video_key`, только у перенесённых курсов) и переключатель «изображение / видео».
- Живое обновление программы опросом (UX-080): опросов нет (7.7), обновление придёт событиями S-06.
- Разбор `learnings` из старого текста: контракт отдаёт типизированный список.

## Ждёт сервера

- Отозвать заявку соавтора нет в `allowed_actions`: доступность выводится из своей строки списка соавторов.
- Длительность и уровень курса: в контракте нет полей.
- Авторы для шапки и своя заявка читаются из первой страницы списка соавторов (100 строк): у `Course` (в отличие от
  `CourseListItem.authors`) отдельных полей нет, хвост большей команды не учитывается.

## Не перенесено (контракт есть)

- `Idempotency-Key` у записи на курс (`enroll`), автор объявления (`CourseUpdate.author`), чтение гостем
  `learner-state`.
- «Подать заявку» по `allowed_actions` (`apply_contributor`), а не по `open_to_contributors`.
